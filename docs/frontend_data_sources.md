## Detailed Audit Notes

### 1. Model Performance (`/models`)
- **Previous State:** Rendered static constants (`0.968`, `94.8%`, `MOCK_ABLATION`).
- **Remediation Action:** Completely rewired to fetch directly from:
  1. `GET /api/v1/models/evaluation` (exposing `results_v2/phase5_evaluation.json` generated on the full held-out test split of 104,623 transactions).
  2. `GET /api/v1/models/ablation` (exposing `results_v2/phase5_ablation.json`).
- **Audit Result:** Head-to-head KPIs, per-scenario recall bars, and the feature group ablation table reflect actual trained model performance.

### 2. Drift Monitoring (`/monitoring`)
- **Backend File:** `results_v2/drift_report.json` generated by `fraudengine/monitoring/drift.py`.
- **Labeling Policy:** Explicitly displays the `simulation_label` tag ("production traffic" or "simulated shift") to avoid deceptive presentation.

### 3. Hash Chain Integrity (`/audit`)
- **Backend Route:** `/api/v1/audit/verify` re-computes SHA-256 hashes sequentially across all audit log rows stored in SQLite. If any record is tampered with, `is_valid` returns `false` with the corrupted index.
